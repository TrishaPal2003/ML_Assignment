# 🤖 Machine Learning Assignments

This repository contains my **Machine Learning course assignments and practical implementations** using **Python, Google Colab, NumPy, Pandas, Matplotlib, and Scikit-Learn**.

The assignments cover the complete machine learning workflow, starting from **Exploratory Data Analysis and data preprocessing** and progressing to **regression, classification, clustering, and dimensionality reduction**.

All assignments are implemented in **Google Colab notebooks (`.ipynb`)**.
